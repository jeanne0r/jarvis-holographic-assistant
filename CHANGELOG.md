# Changelog

## 0.1.0

Initial standalone public release:

- Mechanical 3D holographic cockpit with real voice/audio state reactions.
- Shared hybrid Gemini/Codex routing for text and voice.
- Home Assistant, public web/media tools, local code workflows and persistent memory.
- Natural/dictation modes, manual microphone mute and a separate voice-session stop.
- Portable server, generic profiles, environment-based configuration and optional semantic services.
- English installation/operations documentation, tests, an optional CI template, credential exclusions and publication checks.

This public history intentionally starts fresh. The source deployment's personal history, runtime records and credentials are excluded.
